代数递进 v3.0.3 残局存档

本页仅用于查看汉化覆盖情况。它只会写入浏览器的 APSaveSlot3（第 3 存档位），并把 APLang 设为中文，不会覆盖第 1、2 存档位。

使用前请先备份原存档：在游戏中打开 Options → Export，复制导出的文本另行保存。若要恢复，Options → Import 粘贴原文本即可。

说明

  1. 导入后游戏默认中文；Options 面板顶部的「语言 / Language」按钮可切回英文对照原版。
  2. 该存档是自动生成的功能验证存档，数值被拉满，不代表正常游戏进度。
  3. 离线双击本页即可导入；若浏览器禁止 file:// 使用本地存储，请用本地服务器打开游戏目录后再访问本页。
