## 技术侦察结果

| 项目 | 结论 |
|---|---|
| 语言系统 | 无。没有 `i18n/`、`locales/`、`t()` / `T[lang]` 字典，文本硬编码。 |
| 技术栈 | Vue 2.6.12（CDN 生产构建）+ 原生 JS 数据对象 + jQuery notify。无构建链、无 npm 依赖。 |
| 文本载体 | ① `index.html` 约 2949 个文本节点与按钮/tooltip 属性；② 58 个 JS 文件中的 `title` / `desc` / `chargedDesc` / `name` 等展示字段与字符串拼接；③ `news.js` 新闻数组（含内联 HTML）；④ `changelog.html` 静态更新日志；⑤ `document.title`、`confirm()` / `alert()` / `prompt()`；⑥ canvas 仅 3 处 `getContext`，无 `fillText`，不存在 canvas 文字排版问题。 |
| 存档 | `localStorage.APSaveSlot{1,2,3}` + `APSaveMetaData`，base64(JSON)；`player.options[0..31]` 为选项数组。语言偏好使用独立键 `APLang`，不写入存档，避免旧存档数组长度差异。 |
| 动态文本 | 大量 `{{...}}` 插值与字符串拼接；模板字符串 188 处；与 `format()` 拼接 166 处。静态提取必然漏掉部分运行时整串。 |

## 路线选择：**B + O 混合**

- **B（构建期提取）**：`tools/extract_texts.py` 从 HTML/JS 词法扫描出展示文本候选 `tools/extracted.json`（6360 条），术语表先行，翻译产物固化为 `i18n/zh.json` 与 `i18n/phrases.json`。
- **O（运行时 DOM 边界注入）**：`i18n/engine.js` 在 DOM 写入边界（Vue 的 `createTextNode` / `textContent`、`innerHTML`、`setAttribute`、`document.title`、`alert/confirm/prompt`）按原英文整串查表翻译。不逐字改写 27k 行源码，因此 ID、存档字段、数学符号、分支比较值零改动；原文仍完整保留在源码与词典 key 中。
- **补充**：对未命中整串的拼接文本，用按长度降序的短语表做受保护替换；模板字符串用 `{{0}}` 占位符模式匹配。
- **不采用纯 B 的理由**：文本广泛分布于 Vue 模板与每帧更新的插值中，逐字面量插 `__T(en, zh)` 需修改数千处且会污染 `case` / 对象键 / ID；风险与收益不成比例。
- **不采用纯 O 的理由**：有完整源码，应利用构建期全量提取与术语表保证覆盖，而不是只靠运行时猜测。

## 中英切换（验收项）

- 入口位于游戏内 **Options（设置）** 面板顶部：`语言 / Language: 中文 / English` 按钮。
- 偏好写入 `localStorage.APLang`，切换后 `location.reload()`；默认 `zh`。
- 英文模式引擎完全不激活，DOM 行为与上游逐字一致；中文模式只查表替换显示文本。
- `changelog.html` 同样加载词典与引擎，支持中英切换（该页无游戏设置面板，使用右上角浮动按钮并在此说明降级理由）。

## 绝对不翻译

- 数学符号与函数名：`x`、`y`、`z`、`f(n)`、`g(n)`、`h(n)`、`dx`、`x²`、运算符号、大数后缀。
- 缩写与单位：`RE`、`CE`、`IP`、`QP`、`PP`、`UP`、`ME`、`PE`、`CC`、`IC`、`YC`、`GP`。
- ID / 键名 / 文件名 / URL / CSS 类 / 存档字段 / 版本号 / 人物名（randomtuba 等）/ 品牌与库名（Vue.js、jQuery、break_eternity.js、Discord、Twitter、TI-84）。
- 格式占位符：`{{0}}`、`%s`、`{0}`、HTML 标签、`\n`、新闻 `[red]` / `[rainbow]` 标记。

## 跟版策略

3. 重跑 `tools/build_i18n.py` 生成 `i18n/zh.json` 与 `i18n/phrases.json`，再跑验收脚本。
