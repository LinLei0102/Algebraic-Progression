- 语言切换按钮已在 Options 面板顶部实测可见且文本为「语言 / Language: 中文」；点击写入 `APLang` 并刷新，英文模式回到原版文本。
- **语言按钮唯一性**：`index.html` 的按钮写死在设置面板模板内；引擎中的 `injectControls()` 曾以"找不到 `#tab2disp`"判定为 changelog 页并在右上角注入浮动按钮，但 `#tab2disp` 有 `v-if` 默认不渲染，导致主页面误注入重复按钮。已改为以 `#app` 是否存在区分：游戏主页不再注入浮动按钮（并清理旧版残留），仅 `changelog.html` 使用右上角浮动按钮。实测主页面无浮动按钮、Options 面板按钮正常、changelog 有浮动按钮。
- 教科书长段落初次验收时因主提取器的换行上限被漏掉；已通过 `tools/extract_textbook_long.py` 补提 347 条句子并翻译，覆盖率 322/347，剩余 25 条均为数学公式片段或代码条件。
- 教科书片段二次验收发现 `<b>`/`<br>` 拆分后的文本节点（术语标签、快捷键、建筑段）既不在主提取器也不在长文本补提范围。新增 `tools/collect_dom_residuals.mjs` 直接采集四种状态下的真实 DOM 文本节点，筛出可译片段补入精确词典；复查确认整句全部命中。
- 三次验收（统计页/成就页截图）暴露根因：Vue 将静态译文与插值合并到同一文本节点（如 `你总共已购买 0 Buildings.`），而引擎 `byPhrases()` 原逻辑遇中文即跳过，导致节点内残留英文。修复：移除该短路，并对含中文节点继续做短语替换；同时把 `seconds`/`completed` 等纯小写插值高频词纳入短语表（`build_i18n.py` 放宽 `is_phrase_key`），补入 25 条插值词条。新增 `tools/deep_scan.mjs` 覆盖 62 种状态（13 主标签 + 统计/成就子标签 + 双世界教科书），另用 `part_deep.json` 补译 71 条教科书切断片段。最终统计页显示 `你总共已购买 0 建筑.`、`你玩这个游戏已有 2.11 秒.`、`你已看过 0 新闻滚动条消息.`、`0/90 项成就已完成 (0.00%)`。
- 四次验收（变量按钮/自动正弦/教科书改动章节截图）暴露最终根因：主提取器用 HTMLParser 解析时会**整段跳过 `{{...}}` 插值**，导致三元分支里的字符串字面量（`Gain`、`when reaching`、`ACTIVE`、`game`、`completion`、`Buildings` 等 136 条）从未进入词典。新增 `tools/extract_vue_literals.py` 从 index.html 抽取全部插值字面量，配 `tools/vue_patch_zh.json` 一次性补齐并统一译法（0 冲突）。深度残留降至 225，统计页/教科书页复验无回归。
- 五次验收（Ctrl+F5 仍见教科书改动章节半英半中）确认：不是缓存，而是 `textbook.js` 里 `${Alterations.has(n) ? \`...\` : \`\`}` 这类**嵌套模板**被所有旧提取器漏掉——`jslex` 把外层当单个字符串，旧拆分器遇嵌套反引号即错配。修复 `tools/extract_textbook_all.py` 用栈式状态机解析嵌套模板，句子数从 347 增至 800；分 6 片补译 260+192 条嵌套块句子。强制触发全部条件块后，改动章节渲染为完整中文（抛物线/充能二次升级/四元数集合等），英文残留仅剩 11 条标签/按键/数学式。截图 `screenshots/textbook-alterations-zh.png`。
- 六次验收（统计页截图）暴露最后一批插值变体：`currencies`/`Buyables`/`Imaginary Power Buyables`/`rebuyable`/`hours`/`sine`/`cosine` 等复数形式与连接词来自各 JS 文件的模板字符串，不在 index.html 插值提取范围。新增 `tools/mixed_words.mjs` 在残局状态遍历所有标签采集「半英半中」节点并做词频统计，针对性补入约 30 条高频词/短语（避开 `sec`/`max`/`the` 等会破坏数学式的高风险单词，只补全称词与长短语）。复验统计页混合节点从 40+ 降至 1（仅 `Z-Collider` 专有名词保留）。
- 七次验收（挑战描述 `Currently:` 残留）定位到三层根因：① Vue 2 更新文本 vnode 时直接写 `elm.data`，原引擎只 hook 了 `textContent`/`createTextNode`，切换标签页后动态文本绕过翻译；② 以 `{{0}}` 开头的模板模式用 `([\s\S]*?)` 作首个通配，会把 `Currently: 1.00x` 这类展示前缀整个吞进捕获组，导致后缀被翻译而前缀保持英文；③ `news.js` 里的 `You're currently in the earlygame...` 嵌套模板从未被提取。修复：新增 `CharacterData.data` / `Node.nodeValue` 写入钩子（带重入保护并用原始 setter 回填，避免二次翻译），把首位通配限制为数字式前缀，补入 3 条新闻整串译文，并让 `innerHTML`/`outerHTML`/`insertAdjacentHTML` 在解析前先做整串精确翻译（解决带 `<sup>`/`<span>` 的新闻整句被 DOM 拆碎后永远匹配不上词典的问题）。`tools/probe_currently.mjs` 遍历三种世界与全部挑战子标签，216 条 `Currently`/`当前` 节点中未翻译数从 4 降至 0；深度残留 225→204，三套扫描 0/31–33、0/34、0/0，语言按钮仍唯一。
- 中→英→中往返：`APLang` 独立存储，不修改 `player` 或存档槽，往返后存档可读。
- `changelog.html` 独立加载词典与引擎；因无设置面板，使用右上角浮动按钮（降级理由已记入方案文档）。
